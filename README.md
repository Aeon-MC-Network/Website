## 🔐 Auth System & Permissions Matrix

| Role | Access Level & Permissions |
|---|---|
| **Player** | Standard community access, create public threads, reply to topics, submit confidential support tickets. |
| **Content Creator** | Player permissions + Creator badge, write access to Content Creator Hub & media spotlights. |
| **Mod** | Player/Creator permissions + thread locking, pinning, comment moderation, user warning/muting, and Staff Portal access. |
| **Admin** | Full network management access, role assignment tool, Plan analytics integration, user directory control, and staff portal configuration. |
